# ٧) تجربة المستخدم والشاشات

## ٧-١ المبدأ: نتيجة خلال ٦٠ ثانية

المستخدم غالباً واقف أمام الفرصة على هاتفه. لذلك:
**٨ حقول → حكم أولي فوري → ثم دعوة للتعميق.**
لا نطلب ٤٠ حقلاً قبل أن نُعطيه شيئاً.

## ٧-٢ الشاشات

| # | الشاشة | المحتوى |
|---|---|---|
| ١ | الرئيسية | شرح النموذج في ٣ أسطر + «احسب فرصتك» + مثال جاهز للتجربة |
| ٢ | التقييم السريع | ٨ حقول، نتيجة لحظية أسفل الشاشة تتحدّث مع الكتابة |
| ٣ | التعميق | ٤ تبويبات: الإيرادات · التكاليف · شروط العقد · حالة العقار |
| ٤ | استبيان المخاطر | ١٥–٢٠ سؤال، شريط تقدّم، «غير معروف» خيار صريح |
| ٥ | لوحة النتائج | البطاقة التنفيذية + الرسوم + التبويبات |
| ٦ | ماذا لو؟ | مزالق تفاعلية وتحديث لحظي |
| ٧ | التقرير | عرض كامل + تصدير PDF + رابط مشاركة |
| ٨ | المقارنة | حتى ٥ فرص في جدول واحد، مرتّبة بالعائد المعدّل بالمخاطرة |
| ٩ | فرصي | حفظ ومتابعة وتعديل ونسخ الفرص |

## ٧-٣ الرسوم البيانية

1. **تدفق نقدي تراكمي** مع تحديد نقطة الاسترداد — الرسم الأهم.
2. **أعمدة الإيراد مقابل التكلفة** سنوياً.
3. **Tornado** للحساسية.
4. **توزيع IRR** من مونت كارلو مع خط «عتبة القبول».
5. **مقياس درجة المخاطرة**.
6. **شريط النطاق التفاوضي** الملوّن.

## ٧-٤ اعتبارات عربية (RTL) إلزامية

- اتجاه RTL كامل: التخطيط، الجداول، محاور الرسوم، اتجاه المحور الزمني.
- خط عربي واضح للأرقام الكبيرة، وفاصل آلاف، واختصار ذكي (١٫٢ مليون).
- المصطلح المالي بالعربية مع الإنجليزي بين قوسين أول مرة: «العائد الداخلي (IRR)».
- العملة: الريال السعودي افتراضاً، مع دعم عملات أخرى لاحقاً.
- التقويم: ميلادي وهجري (مدد العقود غالباً هجرية — **فرق ١١ يوماً سنوياً
  يُراكم ثلث سنة على مدى ٣٠ سنة، والمحرّك يجب أن يتعامل معه لا يتجاهله**).
- الجوال أولاً: أغلب الاستخدام سيكون على الهاتف أثناء المعاينة.

## ٧-٥ لمسات تصنع الفرق

- **حفظ تلقائي** — لا يفقد المستخدم إدخالاته أبداً.
- **«لماذا هذا الرقم؟»** بجانب كل افتراضي، يشرح مصدره.
- **مشاركة برابط** لمناقشة الفرصة مع شريك.
- **نسخ فرصة** لتجربة شروط بديلة دون فقد الأصل.
- **وضع الطباعة** نظيف للاجتماع مع المالك.
