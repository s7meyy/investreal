# ١) الرؤية ونموذج الاستثمار

## ١-١ المشكلة

المستثمر يرى فرصة: «شقة إيجارها السوقي ٣٠ ألف، والمالك يقبل ١٢ ألف للسنة
إذا دفعتُ عشر سنوات مقدّماً». الفرق يبدو ٢٠٠٪ ربح. فيقرّر بالحماس،
ويكتشف بعد سنتين أن الفراغ والصيانة والتأثيث والعمولات أكلت الفرق،
وأن ماله مُجمَّد عشر سنوات في عقد قد يسقط لو باع المالك أو مات ورثته تنازعوا.

**المفقود ليس الحماس، بل ثلاثة أشياء:** حساب يشمل كل التكاليف،
تسعير للمخاطر، وسقف تفاوضي يقول «لا تدفع أكثر من كذا».

## ١-٢ الجمهور

| الشريحة | ما يحتاجه |
|---|---|
| مستثمر فرد | حكم سريع: آخذها أم لا؟ وبكم؟ |
| وسيط / مسوّق عقاري | تقرير احترافي يُقنع العميل |
| مجموعة استثمارية | مقارنة عدة فرص وترتيبها |
| مالك العقار | فهم ما يستحقه عرضه حتى لا يبيع رخيصاً |

## ١-٣ نموذج الاستثمار محلّ الدراسة

```
المستثمر ──(دفعة مقدّمة كاملة أو مجزّأة)──> المالك
          <──(حق الانتفاع/الإيجار لمدة N سنة بسعر ثابت منخفض)──
المستثمر ──(إعادة تأجير بسعر السوق سنوياً/شهرياً/يومياً)──> المستأجر النهائي
```

الربح = (إيجار السوق المُحصَّل) − (الإيجار التعاقدي) − (التأثيث والتشغيل) − (تكلفة الفرصة البديلة للمال المجمَّد).

**الأنواع المدعومة:** شقة، دور، فلة، عمارة (وحدات متعددة)، استراحة، محل/معرض،
مكتب، مستودع، أرض (لإقامة نشاط عليها)، مجمّع سكني.

## ١-٤ الحقيقة التي يجب أن تصدم المستخدم: نمذجة مثالك

المثال كما ذُكر: إيجار سوقي ٣٠٬٠٠٠، إيجار تعاقدي ١٢٬٠٠٠، مدة ١٠ سنوات،
دفعة مقدّمة ١٢٠٬٠٠٠ ريال.

الأرقام أدناه ليست تقديراً يدوياً بل مخرجات المحرّك نفسه، ويمكن إعادة توليدها
في أي وقت بـ `npm run report -w @investreal/engine`. الافتراضات: تأثيث ٢٠٬٠٠٠،
نمو إيجارات ٣٪، إشغال ٩٢٪ (٨٥٪ في السنة الأولى)، صيانة ٥٪، إدارة ٥٪،
رسوم ١٬٥٠٠/سنة، إعادة الحال ٨٬٠٠٠، تكلفة فرصة بديلة ١٢٪:

| المؤشر | ميلادي | هجري |
|---|---|---|
| **العائد الداخلي (IRR)** | **١٤٫٢٪** | **١٣٫٧٪** |
| صافي القيمة الحالية @١٢٪ | ١١٬٨٣٥ | ٨٬٨١٧ |
| صافي الربح على ١٠ سنوات | ١١٩٬٨١٠ | ١١٠٬٦٤١ |
| ROI | ٨٢٫٤٪ | ٧٦٫٠٪ |
| استرداد رأس المال | ٥٫٦٣ سنة | ٥٫٦٣ سنة |
| الاسترداد المخصوم | ٨٫٦٤ سنة | ٨٫٦٣ سنة |
| إشغال التعادل | ٥٥٫٢٪ | ٥٦٫٨٪ |

| السيناريو (ميلادي) | العائد الداخلي |
|---|---|
| متشائم | ‎−٠٫١٪ |
| أساسي | ١٤٫٢٪ |
| متفائل | ٢١٫٧٪ |

**الاستنتاجات الأربعة التي تُبرّر وجود المنصّة كلها:**

1. **«٣٠ مقابل ١٢» ليست فرصة ذهبية، بل فرصة جيدة فقط.** العائد ١٤٫٢٪
   يتجاوز تكلفة الفرصة البديلة بنقطتين اثنتين لا أكثر. سبب الوهم: المستثمر
   يقارن ٣٠٠٬٠٠٠ إجمالي بـ١٢٠٬٠٠٠ مدفوعة، ويتجاهل أن المال مجمّد ١٠ سنوات
   وأن نحو خُمس الإيراد يذهب للتشغيل والفراغ.
2. **السيناريو المتشائم يهبط إلى الصفر.** لا خسارة فادحة، لكن كل التعب
   مقابل لا شيء — وهذا هو الاحتمال الذي لا يحسبه أحد.
3. **السقف التفاوضي محسوب:** لعائد ١٢٪ لا تدفع فوق **١٣٬١٨٤ ريال/سنة**،
   ولعائد ٢٠٪ يستحق تجميد عشر سنوات لا تدفع فوق **٩٬٤٨٤ ريال/سنة**
   (إجمالي ٩٤٬٨٣٦ بدل ١٢٠٬٠٠٠). رقم واحد يغيّر التفاوض كله.
4. **التقويم وحده يكلّف نصف نقطة.** نفس الصفقة بعقد هجري تعطي ١٣٫٧٪ بدل
   ١٤٫٢٪، لأن «عشر سنوات هجرية» أقصر بـ١٠٩ أيام من الميلادية — أنت تشتري
   وقتاً أقل بنفس المبلغ. لا أحد يحسب هذا، والمحرّك يحسبه.

> هذه هي القيمة الجوهرية للمنصّة: أن تقول للمستثمر «فرصتك ليست كما تظن،
> وهذا هو السعر الذي تصبح عنده كما تظن».

## ١-٥ مبادئ المنتج

- **الصدق قبل التفاؤل:** الافتراضات الافتراضية محافظة، والسيناريو المتشائم يُعرض دائماً.
- **كل رقم قابل للتتبّع:** كل مؤشر بجانبه «كيف حُسب؟».
- **لا صندوق أسود:** المستخدم يرى جدول التدفقات النقدية كاملاً.
- **العربية أولاً وRTL أصيل**، والأرقام بصيغة واضحة، والتقرير قابل للطباعة والمشاركة.
- **ليست استشارة مالية أو شرعية** — إخلاء مسؤولية ظاهر في التقرير.
