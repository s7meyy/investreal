# منصّة دراسة الجدوى للفرص الإيجارية طويلة المدى

أداة عربية تُقيّم فرص **الاستئجار طويل المدى بدفعة مقدّمة** (من ٥ إلى ٣٠ سنة) —
حيث يستأجر المستثمر عقاراً بسعر أقل من السوق مقابل دفع مقدّم، ثم يُعيد تأجيره
بسعر السوق ويربح من الفرق.

المنصّة تحوّل الفرصة من «إحساس» إلى **قرار مدعوم بالأرقام**:
تدفّقات نقدية، معدّل عائد داخلي، تحليل حساسية، سجلّ مخاطر مُسعَّر،
وسقف تفاوضي واضح لأقصى مبلغ يستحق أن تدفعه.
